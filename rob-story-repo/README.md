# История Роба — Системная Архитектура

Данный репозиторий представляет собой художественную нарративную систему, преобразованную в формат, пригодный для анализа Claude.

## Структура

- `/src` — исходный код персонажей, локаций и событий
- `/maps` — карта зависимостей системы
- `/prompts` — промты для анализа
- `/docs` — документация

## Компоненты

| Компонент | Тип | Роль |
|-----------|-----|------|
| Rob | main_process | Главный исполнитель, проходит эволюцию |
| Bezlikiy | orchestrator | Антагонист, управляет циклами |
| WhiteCube | prison | Место хранения и стирания памяти |
| BlackCube | transformer | Место пробуждения тьмы |
| PrimeLagoon | battlefield | Финальная зона сражений |

## Потоки данных

- Память → стирание → пробуждение → хаос
- Безликий → телепортация → слежка
- Пираты → устройство → попытка восстановления

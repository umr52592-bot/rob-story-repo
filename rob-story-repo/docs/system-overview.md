\# Обзор системы



\## Архитектура



Система построена как многоуровневый нарративный движок с циклическим управлением памятью.



\### Уровни



1\. \*\*Входной слой\*\* — Арена (начальная точка)

2\. \*\*Слой хранения\*\* — Белый Куб (тюрьма/цикл)

3\. \*\*Слой трансформации\*\* — Чёрный Куб (пробуждение)

4\. \*\*Боевой слой\*\* — Праймовая Лагуна (сражения)

5\. \*\*Финал\*\* — Тюрьма Бога (уничтожение порядка)



\### Ключевые зависимости



\- Rob → Bezlikiy (циклическая связь)

\- WhiteCube → BlackCube (переход через трансформацию)

\- Pirates → MemoryDevice (попытка восстановления)

\- Hell + Rovaam → Rob (финальные боссы)



\### Измерения



Система поддерживает мультивселенную:

\- Основная вселенная

\- Измерения для альтернативных версий персонажей

\- Ад (отдельное измерение Хелла)
